## ngu-carousel

This project modernizes and reimplements carousel behavior inspired by
[`@ngu/carousel`](https://github.com/uiuniversal/ngu-carousel) (MIT License).

Copyright (c) uiuniversal / ngu-carousel contributors.

Permission is hereby granted, free of charge, to any person obtaining a copy
of that software and associated documentation files, under the terms of the
MIT License as published by the original authors.

Portions of the public API surface, configuration shape, and documented
behavior were used as a compatibility reference while rewriting the
implementation with Angular 20+ APIs (signals, zoneless-friendly rendering,
Pointer Events, ResizeObserver/IntersectionObserver, and SSR-safe lifecycle).
