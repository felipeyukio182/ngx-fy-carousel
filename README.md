# ngx-fy-carousel

Angular 20+ SSR carousel library with ngu-carousel compatible behavior.

## Workspace

- Library: `projects/ngx-fy-carousel`
- Demo SSR app: `projects/demo`

## Branches

| Branch | Angular |
| --- | --- |
| `angular-20` | 20.x |
| `angular-21` | 21.x |
| `angular-22` | 22.x |

## Scripts

```bash
npm start                 # demo SSR app
npm run build:lib         # build library
npm run build             # build lib + demo
npm test                  # unit tests (Vitest)
npm run serve:ssr:demo    # run SSR server after build
```
